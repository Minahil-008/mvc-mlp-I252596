# MVC MLP Project

## Overview
This project implements a Multilayer Perceptron (MLP) from scratch using NumPy on the MNIST dataset. 

## Folder Structure
- `src/` : contains the Jupyter Notebook (`mlp.ipynb`)
- `data/` : contains the MNIST dataset file
- `report/` : contains the compiled PDF report
- `README.md` : this file

## How to run
1. Open `src/mlp.ipynb` in Jupyter Notebook.
2. Make sure `mnist.npz` is in the `data/` folder.
3. Run all cells sequentially. The notebook outputs:
   - Loss curve
   - Test accuracy
   - Sample predictions for 10 test images
